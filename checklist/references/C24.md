# C24 · viewport meta(P1)

## 介绍

Google 走 **mobile-first indexing**:抓取与评估用的是移动端 Googlebot,移动版页面就是被索引的那一版。
缺 `viewport` meta,移动浏览器按桌面宽度(通常 980px)渲染再缩小,页面被判为不适合移动设备,
移动端排名直接受损——而移动端是绝大多数搜索流量。

一行标签,几乎不会写错,但**一旦被漏(新模板、新落地页、被工具生成的页)就是全站级的表现塌陷**。
成本极低、后果不小,所以留一行专门盯着。

## 边界:本条只查这一个标签

移动端友好还包含点击目标 ≥48×48px、正文字号 ≥16px、对比度 ≥4.5:1 等——
这些是**人可感面**,按 checklist 定义(「分界线是机器可读面 / 人可感面」)明确不在 C 集。
它们归 UI 设计与前端实现,checker 不碰。**本条只判 `<meta name="viewport">` 这一个机器可读声明。**

## 实现指导

- base 模板 `<head>` 里一次写好,所有页面继承:

```html
<meta name="viewport" content="width=device-width, initial-scale=1">
```

- `width=device-width` 是判定的必要成分:告诉浏览器用设备实际宽度当 CSS 视口宽
- **不要加 `user-scalable=no` 或 `maximum-scale=1`** —— 禁用缩放是无障碍反模式,
  且不带来任何 SEO 收益;Safari 已经忽略它,只剩坏名声
- `viewport-fit=cover` 按需加(刘海屏安全区),不影响判定
- 自查:抓页 grep viewport;用 Chrome DevTools 设备模拟或 PageSpeed Insights 的移动端跑分复核
