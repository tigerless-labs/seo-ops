# C13 · 无 soft 404 / 空壳 200(P1)

## 介绍

返回 200 但没有实质内容的页(空模板、「暂无结果」、下架页残留),Google 会自己判成 soft 404——浪费抓取配额,拖累站点质量信号。状态码要说真话。

## 实现指导

- 状态码决策表(仅供参考;语义来源:Google soft 404 文档 + HTTP 语义):

| 情形 | 返回 |
|---|---|
| 内容已删、有替代页 | 301 → 替代页 |
| 内容已删、无替代 | 410(或 404) |
| URL 从来不存在 | 404 |
| 内容临时不可用 | 503 + Retry-After |
| 列表页空结果 | 给实际内容(推荐/说明),或 noindex |

- retired(下架)三件事**同一事务**:路由 301/410 + 移出 sitemap(C2)+ 清入链(C6);禁渲染空模板顶 200
- 错误页本身别被收录:404/410 页面不进 sitemap、无 canonical 指向它
- checker 判定:正文长度阈值(config `MIN_CONTENT_CHARS`,默认 400 字符)+ retired 条目抽查
