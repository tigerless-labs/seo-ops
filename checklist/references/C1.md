# C1 · robots.txt 放行 AI 爬虫(P0)

## 介绍

AI 检索爬虫(OAI-SearchBot、PerplexityBot 等)进不了站,站内 GEO 整体归零——引用、提及都无从发生。
UA 清单分三类(训练 / 检索 / 用户代取),运行时权威是 seo repo 根的 `ai-crawlers.yaml`,新爬虫出现由本系统改 yaml(人审 PR),站点方跟进重新生成。

## 实现指导

**「模板生成」是什么意思**:robots.txt 不许手写维护——站点方写一小段生成代码
(模板),**输入 = `ai-crawlers.yaml`,输出 = robots.txt 文本**,构建时或请求时渲染。
清单更新 → 重新生成即同步,不存在「忘了改」。生成逻辑本身极简:

```
读 ai-crawlers.yaml
→ 对 crawlers 三类下每个 UA 输出一段:
     User-agent: <UA>
     Allow: /
→ 追加通用段(User-agent: * / Allow: /)与 Sitemap: 行
```

期望产出(节选):

```
User-agent: GPTBot
Allow: /

User-agent: OAI-SearchBot
Allow: /

User-agent: *
Allow: /

Sitemap: https://www.example.com/sitemap.xml
```

落点按栈自选(实现自由,产出一致):
- **Next.js**:`app/robots.ts` 读 yaml 返回 rules(框架原生支持,构建时生成)
- **PHP / 静态站**:构建或部署脚本里一步渲染,产物提交
- 任何栈:CI 里跑个 10 行脚本也行——关键是**数据源唯一、禁手改产出**

注意:
- 别用「全站 Disallow 再白名单」的写法——漏一个新 UA 就是全拦
- `policy: allow` 下未列 UA 默认放行(robots.txt 的缺省语义),清单的意义是**显式点名 + checker 有基准可查**
- 自查:`curl <root>/robots.txt`,对照 yaml 逐 UA 确认放行

- [Google:robots.txt 简介与写法](https://developers.google.com/search/docs/crawling-indexing/robots/intro):最大消费方对解析行为的权威说明
- 各 AI 厂爬虫官方文档(UA 清单来源,2026-08-24 已校验):[OpenAI bots](https://developers.openai.com/api/docs/bots) · [Anthropic crawlers](https://support.claude.com/en/articles/8896518-does-anthropic-crawl-data-from-the-web-and-how-can-site-owners-block-the-crawler) · [Perplexity crawlers](https://docs.perplexity.ai/guides/bots)
- [Next.js `app/robots.ts`](https://nextjs.org/docs/app/api-reference/file-conventions/metadata/robots):框架侧生成范式的例子
