# C21 · YMYL 信任块(人审)(P0)

## 介绍

医疗/保险/金融内容(YMYL)是 Google 质量系统重点审查对象:无署名、无审核标注的批量页可拖累**全站**。信任块 = E-E-A-T 的页面可见证据。
依赖 ymyl 判定(T4)与审核真实发生(R2),故归人审。

## 实现指导

- 模板信任块,machine anchor 按 DOM 锚点契约(`data-seo-*`,UI 样式自由、锚点稳定):

```html
<!-- 示例(仅供参考;锚点为本系统 DOM 锚点契约,E-E-A-T 要素依据 Google 质量指南) -->
<div data-seo="byline">
  作者:<a href="/authors/dr-wang">Dr. Wang</a>,持牌保险经纪(CA #0X12345)
</div>
<div data-seo="reviewed-by">
  Reviewed by <a href="/authors/dr-li">Dr. Li</a> · 2026-08-01
</div>
<time data-seo="last-updated" datetime="2026-08-20">最后更新:2026-08-20</time>
```

- 引用列表只用权威来源(域 ∈ `authority-sources.yaml`:官方/政府/学术/行业权威)
- Person JSON-LD 与 DOM **同源渲染**(同一数据行;见 [C12.md](C12.md) 三)
- 作者页(/authors/x)给每位作者立实体:简介 + 资质 + sameAs(执业注册页等)
- 人审:上线前对照 C21 的 YMYL 信任块清单逐项过;**审核必须真实发生,不许挂名**(R2 红线)
