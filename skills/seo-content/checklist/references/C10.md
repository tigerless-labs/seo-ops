# C10 · 缓存 HTML 为无个性化公共版(P0)

## 介绍

CDN 缓存「第一人触发渲染、所有人拿同一份」:个性化内容(用户名、购物车、session)一旦烤进 HTML 被缓存,就会把 A 的信息端给所有人——内容错乱 + 隐私事故,比不缓存更危险。
判定:同一 URL 两次匿名抓取 diff 为空(输出确定性)。

## 实现指导

- 服务端只渲染公共内容;个性化块留空槽,客户端 JS 拉接口旁路填充:

```html
<!-- 示例(仅供参考;通用「缓存 + 旁路个性化」模式) -->
<header>
  <nav>…公共导航,进缓存…</nav>
  <div id="user-slot"></div>          <!-- 缓存版为空 -->
</header>
<script>
  fetch('/api/me', {credentials:'include'})
    .then(r => r.ok ? r.json() : null)
    .then(u => { if (u) renderUserSlot(u) })   // 到浏览器才按人填充
</script>
```

- HTML 里不烤任何 per-request 值:session id、CSRF token、渲染时间戳、A/B 分组
- CSRF token 需要时走 cookie / 接口获取,不进缓存的 HTML
- 与 C15 配对:**先公共版,再开缓存**(顺序反了就是事故)
- 自查:匿名双抓 diff 为空;登录后再抓同 URL,确认响应仍是公共版(个性化在浏览器端出现)
