# C9 · 服务端直出完整正文(P0)

## 介绍

多数 AI 爬虫和部分搜索爬虫**不执行 JS**:CSR 空壳页对它们等于不存在。正文必须在服务端渲染的 HTML 里,JS 只做增强。
判定:禁 JS 抓取的正文长度 ≥ 浏览器渲染版的 90%。

## 实现指导

- 收录页正文 server 渲染(SSG/SSR 皆可,见 C15);交互增强(Vue/React 客户端逻辑)不承载正文
- Next.js(App Router)四条纪律(来源:apsu 交付 Supplement §1.2,已实测有效):
  - 内容页在 **Server Components** 里取数,不移到客户端
  - 别整页/整 layout `"use client"`——交互下推到叶子组件
  - 内容块(轮播、动画区)懒加载别加 `ssr: false`
  - 内容页别调 `cookies()` / `headers()`(会退出 static 生成,变 per-request)
- 折叠区(FAQ 手风琴、tab)内容也要在 HTML 里,交互只控显隐
- 自查:

```bash
# 无 JS 抓取的可见文本量,与浏览器渲染版对比(≥90%)
curl -s -A "<真实浏览器 UA>" <url> | python3 -c "import sys,re;h=sys.stdin.read();t=re.sub(r'<script.*?</script>|<style.*?</style>|<[^>]+>',' ',h,flags=re.S);print(len(' '.join(t.split())))"
```
