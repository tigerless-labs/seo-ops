# C20 · 无跳转链(P2)

## 介绍

A→B→C 的链式重定向浪费抓取配额、每跳折损权重、拖慢用户;历史改版叠加的 301 最容易堆出链。

## 实现指导

- 任意入站 URL 到最终 200 **至多一跳**(hop ≤1)
- 改版迁移时**更新旧 301 映射直指最新 URL**,不叠在上一版 301 之上:

```
# 反例:/old → /mid → /new(两跳,历史叠加)
# 正解:改版时把 /old 的映射改为直指 /new
/old  301→  /new
/mid  301→  /new
```

- 归一(C3)与路径迁移合并成单跳:`http://tigerless.com/old` 应一跳到 `https://www.tigerless.com/new`,别先归一再迁移
- 站内链接直接写最终 URL,别依赖重定向兜底(重定向是给外部旧链的,不是给自己用的)
- 自查:抓取时统计 redirect 链长(config `MAX_REDIRECT_HOPS`);对历史 301 映射表定期重放
