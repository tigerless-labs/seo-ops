# T3 · URL (per page)

> Downstream: **no checker entry** — this one is enforced by review, not by script. Reason below.

## Introduction

The URL is the page's only **irreversible** deliverable.

Body copy wrong? Fix it. Title too long? Edit one line. JSON-LD missing a field? Add it. A
URL, once live, gets linked, bookmarked, and indexed by search engines; changing it means a
301, and a 301 bleeds some authority, makes old backlinks take an extra hop, and cards
already shared on social platforms may simply die.

**So this item's cost structure is inverted: reviewing once is cheap, rework is expensive.**
The checker deliberately doesn't judge it either — judging wouldn't make it changeable, it
would only pile unfixable red items onto the report. **Put the constraint at the point where
it can act** — for URLs, that point is the pre-launch review, not the post-launch scan.

## How to deliver

State the proposed path at the top of each page doc. Rules:

| Rule | Good | Bad |
|---|---|---|
| all lowercase | `/guide/f1-to-h1b` | `/Guide/F1-to-H1B` |
| hyphens between words | `/pet-insurance` | `/pet_insurance`, `/petinsurance` |
| hierarchy reflects category | `/sort/f1`, `/guide/claim-process` | `/page23`, `/p/a1b2` |
| the reader's words | `/dental` | `/oral-health-product-line-b` |
| no dates | `/guide/tax-filing` | `/2024/03/tax-filing` (unless it's news / events) |
| no file extension | `/aboutus` | `/aboutus.html` |
| non-ASCII percent-encoded | a Chinese path segment under `/zh/` lands as `%E4%BF%9D%E9%99%A9...` | raw unencoded characters mixed in |

New URLs go through review — not process for its own sake, but because **this is the only
chance to change them**.

## Common mistakes

- **Internal jargon** — the `sort` in `/sort/f1` is an internal term readers don't recognize; don't introduce more of these in new paths
- **Keyword stuffing** — `/best-cheap-f1-student-health-insurance-usa-2026`: long, and smells like a spam site
- **Pinyin mixed with English** — `/baoxian-guide`: neither Chinese nor English readers recognize it
- **Depth for SEO's sake** — `/insurance/health/student/f1/plan`: five levels with no information gain, just harder to remember
- **Changing after launch** — if you truly must, pair it with a 301 and sync everything: sitemap, internal links, llms.txt (T2), links already shared
