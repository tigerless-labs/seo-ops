# T6 · H1 一句(每页)

> 下游:[C17 标题层级](../../checklist/references/C17.md) — 判「恰好一个 h1」,多了少了都红。

## 介绍

`<h1>` 是页面对机器说的一句「这一页讲的是这个」。**一页一个,不多不少。**

它和 [title](T5.md) 是两件事,常被混为一谈:

| | title | h1 |
|---|---|---|
| 出现在 | 搜索结果 / 浏览器标签 | 页面正文最上方 |
| 读者 | 还没进来的人 | 已经进来的人 |
| 约束 | ≤60 字符,常要塞品牌 | 没有长度硬限,不必塞品牌 |

所以两者**同主题但不必同文字**。title 为了挤进 60 字符往往要缩写,h1 可以写得更自然完整。

## 怎么交

页面 doc 顶部一行:

```yaml
h1: F1 学生签证期间,医疗保险该怎么选
```

对照上面 T5 的例子,title 是 `F1 学生保险怎么选 | Tigerless` —— 同一件事,
h1 说得更完整,因为它不用给品牌留位置。

## 常见错误

- **交了两个** —— 主标题 + 副标题都想当 h1。副标题是 h2,或者干脆不是标题(是一段导语)
- **把站名/logo 当 h1** —— logo 属于全站导航,不是这一页的主题;这是老模板的常见遗留
- **h1 缺失,只有一个视觉大字** —— **字号大 ≠ h1**。视觉呈现归 UI,语义层级归这里;
  一个 `<div class="hero-title">` 再大,机器也看不出它是标题
- **h1 是营销标语** —— 「让保障如影随形」,机器和读者都不知道这页在讲什么
- **每页 h1 都一样** —— 通常是模板把品牌 slogan 放进了 h1;等于每页都没声明主题
