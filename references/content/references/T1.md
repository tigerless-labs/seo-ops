# T1 · 品牌名统一写法 + 官方社媒账号清单(站级)

> 下游:[C12 JSON-LD](../../checklist/references/C12.md) — 欠供则 Organization 的 `name` / `sameAs` 无从填,C12 红。

## 介绍

搜索引擎和 AI 不认「公司」,只认**实体**。它靠两样东西确认「这三个站说的是同一家公司」:
一个统一的名字,和一组指向同一批官方账号的链接(`sameAs`)。

名字写法不统一 —— Tigerless / TigerLess / 泰格勒思 —— 引擎可能当成三个不同实体,
三份权威度各自积累,谁也长不大。`sameAs` 的作用是**把散落各处的品牌痕迹并成一个**:
LinkedIn 页、X 账号、维基条目、Crunchbase 词条互相印证,实体才立得住。

这条交一次,变了才改(改名、新开账号、账号停用)。

## 怎么交

一张表,放在站级配置里(不是每页 doc):

| 字段 | 内容 | 说明 |
|---|---|---|
| 法定名称 | Tigerless Insurance Services, Inc. | 与营业执照/注册文件一致 |
| 展示名 | Tigerless | 页面上、title 里用的 |
| 中文名 | 泰格勒思 | 中文页用;没有就写「无」,别临时造一个 |
| 简称/别名 | TGL | 有就写,没有留空 |
| logo | 完整 URL | **≥112×112 px、PNG/JPG(不能是 SVG)**、正方或接近正方、背景不透明 |
| 官方账号 | 每行一条**完整 URL** | 见下 |

官方账号逐条列全 URL,不是 handle:

```
https://www.linkedin.com/company/tigerless
https://x.com/tigerless
https://www.youtube.com/@tigerless
https://www.crunchbase.com/organization/tigerless
```

## 常见错误

- **交 handle 不交 URL** —— `@tigerless` 在不同平台指向不同的东西,机器没法解析
- **把员工个人号混进来** —— `sameAs` 声明的是「这也是本公司」,个人号不是;混进去会污染实体图
- **LinkedIn 个人页当公司页** —— `/in/xxx` 是个人,`/company/xxx` 才是公司
- **账号停用了没清** —— 指向 404 的 `sameAs` 是负分,不是中性
- **logo 交 SVG** —— Google 的 Organization logo 明确不接受 SVG,交了等于没交
- **三个站各交各的** —— 本条是**公司级**的,三站共用一份;各交各的就白做了实体归并
