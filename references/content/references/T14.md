# T14 · image alt copy (per page)

> Downstream: [C18 img width/height and alt](../../checklist/references/C18.md) — judges "does every `<img>` have an `alt` attribute".

## Introduction

`alt` is an image's only machine-readable face. Crawlers, AI, and screen readers can't see
the image; they read only this line. Image search indexes on it; when AI describes a page's
content, this is how it knows what's in the image.

One key distinction: **C18 judges "is there an alt attribute", not "is the alt non-empty".**

- content image → `alt="…description…"`, tells machines what's in it
- decorative image → `alt=""`, **which is the correct form** — an explicit "no information here, skip it"
- nothing at all → machines can only guess, usually from the filename, and the guess comes out as `hero-bg-v3-final.jpg`

So what you deliver is really two kinds of information: **which images carry content (with
copy), and which are pure decoration (marked as such)**.

## How to deliver

Alt lives in this page's SEO appendix like every other supply item (the section at the end of
the page doc), but **keyed by image filename**, not "figure 1 / figure 2" — numbers follow
the body, and one image added, removed, or moved shifts them all; filenames don't.

Write **while looking at the image**: face the image itself, one entry per image.

```yaml
images:
  - file: gap-timeline.png
    alt: Timeline of the three F1-to-H1B status-gap scenarios and how insurance bridges each
  - file: claim-flow.png
    alt: The five claim steps — file documents, review, supplement, adjudicate, pay out
  - file: section-divider.svg
    alt: decorative          # mark pure decoration like this; frontend renders it as alt=""
```

How to write:

- **One sentence, what is in the image** — not why the image is here
- Long enough to convey it, typically 10-25 chars; no need for a full sentence
- If the image carries key data or a process, write the key information in (claim-flow.png
  above) — **AI can't read the image, only this line; only when this line is complete has
  the image's information truly made it onto the page**

## Common mistakes

- **Parroting the filename** — `alt="hero-image-2"`: as good as nothing
- **Keyword stacking** — `alt="F1 insurance student insurance international student health insurance cheap"`: read as an abuse signal
- **Describing decoration** — `alt="blue divider line"` is noise; decoration gets marked "decorative"
- **Writing "image", "picture", "photo"** — likewise as good as nothing
- **People photos captioned as job functions** — `alt="our team"` loses to `alt="claims advisor Zhang Ming taking a consultation call in the office"`
- **Chart numbers left out** — charts are the densest images on the page; alt is the last place to skimp
