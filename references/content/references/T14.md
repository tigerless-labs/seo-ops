# T14 · 图片 alt 文案(每页)

> 下游:[C18 图片属性齐](../../checklist/references/C18.md) — 判「每张 `<img>` 有没有 `alt` 属性」。

## 介绍

`alt` 是图片唯一的机器可读面。爬虫、AI、屏幕阅读器都看不见图,只能读这一行字。
图片搜索靠它索引,AI 描述页面内容时靠它知道图里是什么。

一个关键区分:**C18 判的是「有没有 alt 属性」,不是「alt 是不是非空」。**

- 内容图 → `alt="…描述…"`,告诉机器图里有什么
- 装饰图 → `alt=""`,**这是正确写法**,等于明确说「这图没信息,跳过」
- 什么都不写 → 机器只能猜,通常去猜文件名,猜出来的是 `hero-bg-v3-final.jpg`

所以你交的其实是两类信息:**哪些图有内容(配文案)、哪些图纯装饰(标一下)**。

## 怎么交

**这是唯一不进 SEO 头部块的供给项** —— 其余字段都单独成块与正文分开([T7](T7.md) 的大纲也是),
alt 反过来:**写在正文的图片位旁边**。理由是它必须贴着图,写在头部块里就要靠「图 1 / 图 2」
跟正文对号,图一增删移动就对不上,而且写的人看不到图,写出来的必然是凑数的一句。

在页面 doc 里,图片位旁边直接写:

```markdown
[图 1] gap-timeline.png
alt: F1 到 H1B 身份转换期的三种情形与各自的保险衔接时间轴

[图 2] section-divider.svg
alt: 装饰          ← 前端落成 alt=""

[图 3] claim-flow.png
alt: 理赔流程五步:提交材料、审核、补件、核定、打款
```

写法:

- **一句话,说图里是什么**,不是说这图为什么在这
- 长度够表达就行,一般 10–25 字;不需要写成完整句子
- 图里有关键数据/流程的,把关键信息写进去(上例图 3)——
  **AI 读不到图,只能读到这句;这句写全了,图里的信息才算真的上了页**

## 常见错误

- **复读文件名** —— `alt="hero-image-2"`,等于没写
- **堆关键词** —— `alt="F1保险 学生保险 留学生医疗保险 便宜"`,会被当作滥用信号
- **给装饰图写描述** —— `alt="蓝色分隔线"` 是噪声;装饰图就标「装饰」
- **写「图片」「image」「照片」** —— 同样等于没写
- **人物照写成岗位** —— `alt="我们的团队"` 不如 `alt="理赔顾问张明在办公室接听咨询电话"`
- **漏掉图表里的数字** —— 图表是信息密度最高的图,alt 最不该省
