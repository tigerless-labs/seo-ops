# C13 · no soft 404s (P1)

## Introduction

Pages that return 200 with no substantive content (an empty template, "no results", leftovers of a retired page) Google will classify as soft 404s on its own -- wasting crawl quota and dragging down the site's quality signal. Status codes must tell the truth.

## Implementation guidance

- Status-code decision table (for reference only; semantics source: Google's soft 404 doc + HTTP semantics):

| Situation | Return |
|---|---|
| Content deleted, replacement exists | 301 -> the replacement page |
| Content deleted, no replacement | 410 (or 404) |
| URL never existed | 404 |
| Content temporarily unavailable | 503 + Retry-After |
| List page with empty results | serve real content (recommendations/explanation), or noindex |

- Retirement is three things in **one transaction**: route to 301/410 + remove from sitemap (C2) + clean inbound links (C6); rendering an empty template under a 200 is forbidden
- Error pages themselves must not get indexed: 404/410 pages stay out of the sitemap, and no canonical points at them
- Checker verdict: body length threshold (config `MIN_CONTENT_CHARS`, default 400 characters) + sampling of retired entries
