# C5 · IndexNow key 文件可达(P1)

## 介绍

IndexNow 是推送式收录协议(Bing 系;ChatGPT search 用 Bing 索引,这是 GEO 收录加速器)。
站根的 `{key}.txt` 是域名所有权证明——引擎收到推送后回来 fetch 它验证,防止第三方冒名灌 URL。

## 实现指导

- 生成随机 key(≥8 位十六进制即可),放站根:`/{key}.txt` — **文件名与文件内容是同一个 key 串**
  (引擎按推送请求里的 key 拼 URL 来取文件,再比对内容),常驻不删;默认放站根,
  自定义位置用 `keyLocation` 参数(少用,放子目录会限制可提交范围)
- **key 报给 seo-ops 登记**(`~/.config/seo-ops/.env` 的 `INDEXNOW_KEYS`)——C5 的判定前置,
  未登记 checker 只能记 N.A.;key 不要 commit 进公开 repo
- 发布/更新钩子(blog API 发布成功后)POST 变更 URL:

```json
// 示例(仅供参考;来源:indexnow.org 协议文档)
POST https://api.indexnow.org/indexnow
Content-Type: application/json
{
  "host": "www.example.com",
  "key": "a1b2c3d4e5f6",
  "keyLocation": "https://www.example.com/a1b2c3d4e5f6.txt",
  "urlList": ["https://www.example.com/blog/new-post"]
}
```

- 批量变更合并一次 POST(协议单次上限 1 万条);响应 200/202 即受理
- checker 只验 key 文件可达;推送行为看钩子日志
