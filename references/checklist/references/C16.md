# C16 · snippet controls set (P1)

## Introduction

`max-snippet:-1` authorizes engines to quote body text at unlimited length (the precondition for featured snippets and AI-answer citations); `max-image-preview:large` authorizes large image previews (one of the Google Discover thresholds). GEO's authorization switch, at the cost of one line.

## Implementation guidance

- The head template outputs on every **indexed page** site-wide:

```html
<!-- Example (for reference only; directive source: Google robots meta docs) -->
<meta name="robots" content="max-snippet:-1, max-image-preview:large">
```

- Non-indexed pages (business/logged-in) use `noindex`; never mix it with the authorization directives above in the same content attribute
- `max-video-preview:-1` may be added (when there is video content)
- Self-check: fetch the page and grep the robots meta; confirm no other channel (HTTP header `X-Robots-Tag`, other meta tags) outputs conflicting directives
