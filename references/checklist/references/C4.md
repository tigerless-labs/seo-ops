# C4 · Core Web Vitals pass (P1)

## Introduction

One of Google's ranking signals; it measures three things: LCP (loading, <2.5s), INP (interaction responsiveness, <200ms), CLS (layout stability, <0.1).
The verdict uses CrUX real-user 75th percentile (field data); a Lighthouse score is only a lab reference. **Needs to be live plus about 28 days of real traffic before data exists**; until then the checker records N.A.

## Implementation guidance

- **LCP**: indexed pages go through cache / prerendering (see C15); hero image `fetchpriority="high"` + preload, compressed (WebP/AVIF); critical CSS inlined
- **INP**: keep JS execution in check, split long tasks (`scheduler.yield` / frame slicing); separate content pages from interactive pages, hang few scripts on content pages
- **CLS**: hard-code image width/height (see C18); fonts `font-display: swap` + preload; reserve placeholder space for ad/embed slots
- Self-test before delivery: Lighthouse / PageSpeed Insights (lab data, for self-checking); once live, watch CrUX (the field block at the top of PageSpeed Insights is exactly that)
- Acceptance only trusts CrUX; for a new site's first 28 days the checker records N.A. (reason=need-crux-data)
- **Checker prerequisite (wire up the CrUX API, about 3 minutes)** -- free, no card required, 150 requests/minute; the data is public
  (any domain can be queried, no site ownership needed). No key filled in = N.A. (reason=need-crux-key):
  1. Google Cloud, **any project** (new or existing both fine; it has no binding to the site)
  2. Search **Chrome UX Report API** -> **Enable**
  3. **Credentials -> + CREATE CREDENTIALS -> API key**
     (the "Create credentials" wizard on the API detail page also works: choose *Public data* -> Next;
     the line "This API doesn't require credentials" means no OAuth is needed -- the key must still be created)
  4. Once created, **Edit API key** -> under *API restrictions* check **Chrome UX Report API** -> Save
     (leave Application restrictions at **None** -- the script runs from a local machine with no fixed IP); takes up to 5 minutes to activate
  5. **Show key**, copy the `AIza...` -> put it in `CRUX_API_KEY` in `checker/.env`
  6. Verify: `python3 checker/run.py --site <id> --page-sample 1 --max-pages 1`;
     the C4 row showing LCP/INP/CLS values means it passes; showing `need-crux-data` means the key is fine and that domain lacks sample volume
  - Don't reuse a key another service is already using (permission scope and usage stats get mixed together); the key is a secret and stays out of public repos
