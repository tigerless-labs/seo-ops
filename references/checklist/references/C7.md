# C7 · llms.txt 存在(P2)

## 介绍

给 LLM 的站点目录(社区约定,llmstxt.org,无大厂正式背书——故 P2):一段站点说明 + 重点页清单(每条一句话摘要),帮 AI 引擎快速理解站里有什么、该引哪页。
重点页取舍与摘要文案由 content 团队供(T2);文件生成与挂载归工程。

## 实现指导

- markdown 纯文本,放站根 `/llms.txt`;建议从 T2 清单数据生成,不手写:

```markdown
<!-- 示例(仅供参考;格式来源:llmstxt.org 提案) -->
# Tigerless
> 面向在美留学生与新移民的保险平台:比价、指南、在线投保。

## 核心页面
- [F1 转 H1B 保险指南](https://www.example.com/guide/f1-to-h1b):身份转换期保险衔接的完整说明
- [保险比价](https://www.example.com/compare):主流计划横向对比

## 博客
- [博客首页](https://www.example.com/blog):全部指南与更新
```

- pSEO 页集以 hub 页代表,不逐页罗列;站点结构变更时随之更新
- 摘要一句话说清「这页回答什么问题」——它是给 LLM 的检索提示,不是营销文案

## 权威参考
