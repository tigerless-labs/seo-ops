# C7 · llms.txt exists (P2)

## Introduction

A site directory for LLMs (a community convention, llmstxt.org, with no formal big-vendor endorsement -- hence P2): one paragraph describing the site + a list of key pages (one-line summary each), helping AI engines quickly grasp what the site holds and which page to cite.
Which pages make the cut and the summary copy come from the content team (T2); generating and mounting the file belongs to engineering.

## Implementation guidance

- Plain markdown text at the site root `/llms.txt`; generate it from the T2 list data rather than writing by hand:

```markdown
<!-- example (for reference only; format source: the llmstxt.org proposal) -->
# Acme
> An insurance platform for international students and new immigrants in the US: comparison, guides, online enrollment.

## Core pages
- [F1 to H1B insurance guide](https://www.example.com/guide/f1-to-h1b): the complete walkthrough of insurance continuity across the status change
- [Insurance comparison](https://www.example.com/compare): mainstream plans side by side

## Blog
- [Blog home](https://www.example.com/blog): all guides and updates
```

- pSEO page sets are represented by their hub page, not listed page by page; update the file whenever the site structure changes
- Each summary states in one sentence "what question this page answers" -- it's a retrieval hint for LLMs, not marketing copy
