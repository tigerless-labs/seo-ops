# C3 · 网址归一(P0)

## 介绍

www/裸域 × http/https × 尾斜杠能拼出一页多址,权重分裂、抓取重复;C8 的 canonical 判定以归一结果为基准。
**需真实域名才能测**(DNS/证书层),本地部署时 checker 记 N.A.。

## 实现指导

- server / CDN **一处配置**:全部变体 301 到唯一 canonical host;选定三件事——www 或裸域、强制 https、尾斜杠约定
- 变体必须**一跳直达**最终形态(同时受 C20 约束),别 http→https→www 链式:

```nginx
# 示例(仅供参考;nginx 写法,CDN 规则同理)
server {
    listen 80;  listen 443 ssl;
    server_name tigerless.com;              # 裸域(含 http)
    return 301 https://www.tigerless.com$request_uri;   # 一跳直达最终形态
}
```

- 尾斜杠:选定一种(建议无尾斜杠),另一种 301 过去,框架层配置(Next `trailingSlash`、nginx `rewrite`)
- 自查:`curl -I` 四变体(http/https × www/裸域),全部 301 且 Location 一致、hop=1
