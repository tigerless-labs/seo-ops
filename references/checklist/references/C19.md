# C19 · OG 分享卡全套(P2)

## 介绍

链接被分享到微信 / X / Slack 时的预览卡由 Open Graph 标签决定;缺失则平台乱抓图文,分享点击率直接掉。

**标签在 ≠ 值对。** 2026-08-25 并入两项取值校验:

- **`og:type` 取值** — 必须是合法 OG type;且**页面自称是文章**(JSON-LD 出现 `Article` /
  `BlogPosting` / `NewsArticle`)时,`og:type` 必须是 `article`,不能是 `website`。
  这里用的是与 C12 同一条**自证触发**原则:页面自己声明了身份,机器就能交叉验,**零外部输入**。
  (声明了文章类 JSON-LD 却写 `og:type=website`,是模板把首页那套 head 复制到文章页的典型痕迹。)
- **`og:image` 必须是绝对 URL** — 相对路径在多数平台抓不到,卡片会退化成无图。

**twitter 标签只查 `twitter:card`,不查全套**——X 官方规定 `twitter:title` / `description` /
`image` 缺失时**回落到对应的 `og:*`**,所以要求全套是纯冗余。只有 `card` 没有 og 等价物,必须显式写。

## 实现指导

- head 模板输出全套(og:url 用归一 URL,与 C8 同源):

```html
<!-- 示例(仅供参考;协议来源:ogp.me;卡片格式来源:X Cards 文档) -->
<meta property="og:title"       content="F1 转 H1B,保险别断档">
<meta property="og:description" content="Gap 期三种情况一张图讲清">
<meta property="og:type"        content="article">
<meta property="og:url"         content="https://www.example.com/guide/f1-to-h1b">
<meta property="og:image"       content="https://www.example.com/og/f1-h1b.png">
<meta property="og:image:width"  content="1200">
<meta property="og:image:height" content="630">
<meta name="twitter:card"       content="summary_large_image">
```

- og:image:**绝对 URL**、1200×630(config 参数)、文件可达且不被 robots 拦
- og:type:文章页 `article`、首页与栏目页 `website`、产品页 `product`;**由页面数据决定,别写死在 base 模板里**
- 文案默认同源 title/description;content 单独供稿时用差异版(T9)
- 自查:抓页 grep meta;用分享调试器(opengraph.xyz、各平台 card validator)过样本页
