# C19 · social preview cards complete (P2)

## Introduction

When a link is shared to WeChat / X / Slack, the preview card is determined by the Open Graph tags; when they are missing, the platform scrapes text and images at random and the share click-through rate drops outright.

**Tags present ≠ values right.** Two value validations merged in on 2026-08-25:

- **`og:type` value** — must be a legal OG type; and when the **page claims to be an article** (JSON-LD contains `Article` /
  `BlogPosting` / `NewsArticle`), `og:type` must be `article`, not `website`.
  This uses the same **self-evidencing trigger** principle as C12: the page declared its own identity, so the machine can cross-validate, **zero external input**.
  (Declaring article-class JSON-LD while writing `og:type=website` is the classic trace of a template copying the homepage head onto article pages.)
- **`og:image` must be an absolute URL** — most platforms cannot fetch relative paths, and the card degrades to imageless.

**Of the twitter tags only `twitter:card` is checked, not the full set** — X officially specifies that missing `twitter:title` / `description` /
`image` **fall back to the corresponding `og:*`**, so requiring the full set is pure redundancy. Only `card` has no og equivalent and must be written explicitly.

## Implementation guidance

- The head template outputs the full set (og:url uses the normalized URL, same source as C8):

```html
<!-- Example (for reference only; protocol source: ogp.me; card format source: X Cards docs) -->
<meta property="og:title"       content="F1 to H1B: don't let coverage lapse">
<meta property="og:description" content="The three gap scenarios explained in one chart">
<meta property="og:type"        content="article">
<meta property="og:url"         content="https://www.example.com/guide/f1-to-h1b">
<meta property="og:image"       content="https://www.example.com/og/f1-h1b.png">
<meta property="og:image:width"  content="1200">
<meta property="og:image:height" content="630">
<meta name="twitter:card"       content="summary_large_image">
```

- og:image: **absolute URL**, 1200×630 (config parameter), file reachable and not blocked by robots
- og:type: `article` on article pages, `website` on the homepage and section pages, `product` on product pages; **driven by page data, never hard-coded in the base template**
- Copy defaults to the same source as title/description; use the differentiated version when content supplies one separately (T9)
- Self-check: fetch the page and grep the metas; run sample pages through share debuggers (opengraph.xyz, each platform's card validator)
