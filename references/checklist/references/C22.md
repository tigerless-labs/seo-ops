# C22 · hreflang reciprocal pairs (P1)

## Introduction

The en/zh versions pair up via hreflang; only then does the engine know to serve the Chinese page to Chinese users. One missing side (A points to B, B does not point back) voids the whole group; wrong pairing makes the language versions cannibalize each other's rankings.

**Split verdict (machine part added 2026-08-28)**: what the annotations *point at* is machine-checkable; whether the pairs *close* depends on the language configuration of "which pages should be bilingual" (T8), hence stays human.

- **Checker**: every distinct hreflang target URL found on sampled pages (capped by config `HREFLANG_TARGET_SAMPLE`) must return **200 direct** — engines silently drop non-200 entries, and an entry that 3xx-redirects is also dropped (hreflang must name the final canonical URL, not a hop into a redirect chain). Any violation is red on its own, no human needed.
- **Human review**: reciprocity closure (A lists B ⇔ B lists A, both self-referencing) + x-default presence, checked pair by pair against the language list (T8).

## Implementation guidance

- Bilingual pages output the complete group on **both sides** (including self-reference + x-default), URLs in normalized absolute form:

```html
<!-- Example (for reference only; source: Google localized versions docs) — the en page and the zh page output the same group -->
<link rel="alternate" hreflang="en" href="https://www.example.com/guide/f1-to-h1b">
<link rel="alternate" hreflang="zh" href="https://www.example.com/cn/guide/f1-to-h1b">
<link rel="alternate" hreflang="x-default" href="https://www.example.com/guide/f1-to-h1b">
```

- Key rule: **reciprocity must close** (the en page lists zh, the zh page also lists en, and both include themselves); x-default points to the default language version
- Language codes use ISO 639-1 (`zh`, or the finer-grained `zh-Hans`); do not invent your own
- Monolingual pages (en only / zh only, declared in T8) output no hreflang
- Sitemap-level `xhtml:link` alternates are kept but do not count as a substitute (third-party engines and AI crawlers mostly read only the page)
- Human review: check reciprocity closure pair by pair against the language configuration list (T8)
