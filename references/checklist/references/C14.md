# C14 · 无 anti-flicker 藏页脚本(P1)

## 介绍

A/B 测试类工具的 anti-flicker 机制把 `<body>` 置 `opacity:0` 直到脚本初始化——执行 JS 的爬虫可能截到空白页。内容在 DOM 里但视觉不可见,C9 的文本判定抓不到,故单列。

## 实现指导

- 已知危险形态(checker 按 config `BODY_HIDE_PATTERNS` 扫,清单随新工具追加):
  - VWO SmartCode 的 `hide_element='body'` 配置
  - Google Optimize 系的 anti-flicker snippet(`.async-hide { opacity: 0 }`)
  - 任何「`body { opacity: 0 }` + JS 超时恢复」的等价物
- 整改方向(按优先序):
  1. A/B 分流放**服务端**(edge/中间件按 cookie 分桶,渲染即最终版,无闪烁问题)
  2. 用工具的**无闪烁模式**(如 VWO 的 SmartCode 无 hide 配置)
  3. 实在要 anti-flicker:只 hide 被实验的**具体元素**,永不 hide body/主容器
- 新第三方脚本(A/B、统计、聊天挂件)上线前过 technical 评审——它们都在爬虫可见面上
- 自查:grep pattern + 渲染后首屏截图非空白;发现新隐藏机制 → 提给本系统进 config 清单
