# C11 · title/description unique and bounded (P1)

## Introduction

The title is the primary ranking and click surface in the SERP; the description drives CTR. Too long gets truncated; duplicated, pages dilute each other and the engine rewrites them itself.

## Implementation guidance

- Generated by the head template, one formula site-wide, main keyword up front:

```html
<!-- example (for reference only; the formula is this system's convention, lengths follow Google's display-width practice) -->
<title>F1 to H1B Insurance Guide (2026) | Tigerless</title>
<meta name="description" content="Does coverage lapse between the end of OPT and H1B taking effect? Bridging options, costs, and enrollment timing for all three cases, in one read.">
```

- title <=60 characters, description <=150 characters; values come from the page's data row (content-supplied, T5), the template only assembles the formula
- Uniqueness rests on the data rows differing; don't splice the same boilerplate into the template ("The professional insurance platform -- XX" reused site-wide = collective duplication)
- `<meta name="description">` is allowed in exactly one place, the head template (greppable); when a page-level value is missing, **prefer leaving it empty** and letting the engine excerpt, over falling back to a site-level default line (default copy = manufacturing duplication)
- Note: Google may rewrite the displayed title; that doesn't affect this verdict (the verdict is about what you emitted)
