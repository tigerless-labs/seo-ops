# C17 · heading levels don't skip (P2)

## Introduction

h1-h6 is the table of contents the page gives to machines: one h1 per page (the book title), h2 chapters, h3 sections, nested level by level. AI answer extraction often lifts the whole "h2 question + first paragraph" block; broken hierarchy = broken table of contents.

## Implementation guidance

- The template guarantees **exactly one** `<h1>` per page (same topic as the title; the wording may differ):

```html
<!-- Example (for reference only; semantics source: MDN heading element docs) -->
<h1>F1-to-H1B insurance guide</h1>
  <h2>Will coverage lapse during the transfer?</h2>
    <h3>Three gap-period scenarios</h3>
  <h2>Which insurance should I buy?</h2>     <!-- returning to h2 is legal; h4 right after h2 = skipped level, red -->
```

- Components must not embed an h1 (card and modal titles use h2+ or non-heading tags)
- Level is determined by **structural nesting depth**; font size belongs to CSS, decoupled from the tag (never pick a tag for its font size)
- Headings inside hidden content also count in the sequence (tabs/collapsed areas); factor this in at design time
- Self-check: parse the heading sequence from the DOM (exactly the checker's verdict); browser extensions (HeadingsMap and the like) for visual self-checking
