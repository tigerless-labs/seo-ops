# C30 · link hygiene (P2)

## Introduction

Two per-anchor rules, one DOM scan (merged into one check — same fetch, same element):

- **Every link needs a machine-readable label**: visible anchor text, or an `alt` on the image inside it, or an
  `aria-label`. Anchor text is how engines (and screen readers) know what the target page is about — it's ranking
  signal for the **target**, not the source. A bare icon link is a link that transfers no meaning
- **External `target="_blank"` links carry `rel="noopener"`**: without it, the opened page gets a live
  `window.opener` handle back to yours — the reverse-tabnabbing attack (the opened tab quietly navigates your tab
  to a phishing clone). Modern browsers imply `noopener` on `_blank` by default (since ~2021); the explicit
  attribute covers older browsers and makes the intent auditable — defense in depth, hence P2 not higher

## Verdict method

Scan every `<a>` on sampled pages. Skipped: `javascript:` / `mailto:` / `tel:` / pure-fragment hrefs (not
navigation links in the SEO sense). Label check passes on any of: non-empty text content, an `img` with non-empty
`alt` inside, an `aria-label` on the anchor. The noopener check fires only on **external** `_blank` links
(same-host `_blank` opens your own site; the opener handle is harmless).

Overlap note: an image-only link whose image lacks `alt` will also show up in C18 (missing alt attribute).
Deliberate — C18 judges the img element, C30 judges the link's usability; fixing the alt clears both.

## Implementation guidance

- Icon/logo links: put the label on the anchor (`aria-label="Home"`) or the image (`alt="Tigerless home"`);
  never leave both empty
- `target="_blank"`: fix at the template/component level, not per-link — a single `ExternalLink` component (or a
  markdown renderer option: most support `linkify` hooks) stamps `rel="noopener noreferrer"` on every external
  link forever. `noreferrer` additionally suppresses the Referer header (pairs with C28's Referrer-Policy)
- Anchor copy quality (beyond this check's structural floor): descriptive over generic — "insurance handover
  timeline", not "click here". That's a content-side (T set) concern; the checker only guards the floor of
  "a label exists at all"
- Self-check: `grep -o '<a [^>]*>' page.html` and look for anchors with `target="_blank"` but no `rel`
