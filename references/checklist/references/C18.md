# C18 · 图片属性齐(尺寸 + alt)(P2)

## 介绍

同一个 `<img>` 标签上的两个必备属性,一次 grep 查完,故合为一条(2026-08-25 并入 alt):

- **显式 width/height** — 不写宽高的图片加载完成时把下方内容挤跳,是 CLS(C4)最常见的病因。浏览器有宽高才能预留占位。
- **alt 属性** — 图片的机器可读面。图片搜索靠它索引、AI 靠它理解图在讲什么、屏幕阅读器靠它朗读。
  **判定的是「有没有 alt 属性」,不是「alt 非空」**:装饰性图片写 `alt=""` 是**正确**写法
  ——那是在明确告诉机器「这图无信息,跳过」;真正的错是**整个属性缺席**,机器只能猜。

## 实现指导

- 所有 `<img>` 写 `width`/`height` + `alt` 三件套(尺寸给真实像素比即可,CSS 负责缩放):

```html
<!-- 内容图:alt 描述图讲了什么,不堆关键词 -->
<img src="/img/gap-timeline.webp" width="1200" height="630"
     alt="F1 到 H1B 的三种 gap 情形与保险衔接时间轴"
     style="max-width:100%; height:auto">

<!-- 装饰图:属性在,值为空 —— 合法且正确 -->
<img src="/img/divider.svg" width="24" height="24" alt="">
```

- alt 文案归 **content 团队供给**(T 集),不由前端现编;装饰图在页面 doc 里标注「装饰」即可

- 或 CSS `aspect-ratio: 1200 / 630` 占位(动态尺寸图适用)
- Next.js 用 `next/image`(强制传尺寸,自动达标);背景图不受本条约束但注意别当正文图用
- iframe/视频嵌入同理预留宽高
- 自查:模板 grep `<img`,缺 width/height 或**缺 alt 属性**即红(站点 CI 可加同规则,双保险)
