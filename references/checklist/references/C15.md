# C15 · 渲染成本与声明一致(P2)

## 介绍

收录页渲染成本不得为 per-request:SSG 在 build 时渲染天然达标;SSR 必须靠 CDN 缓存把「每请求现算」压成「每天算一次」。这同时是 LCP(C4)的主要抓手。
判定按站点渲染策略声明分支,策略未声明则无从判。

## 实现指导

- **SSG/ISR 路由**:build 时渲染,天然达标;缓存头非必须(加了提速 LCP)
- **SSR 路由**:响应头(CDN 层生效):

```http
# 示例(仅供参考;指令语义来源:MDN / RFC 9111、RFC 5861)
Cache-Control: public, s-maxage=86400, stale-while-revalidate=604800
```

  语义:CDN 缓存 1 天(`s-maxage` 只作用于共享缓存);过期后 7 天内先回旧版、后台再生(SWR,用户无感)
- **业务/登录态页**:`Cache-Control: no-store` 照旧
- 前置:开缓存前先满足 C10(公共版),否则缓存出事故
- Cloudflare 注意:默认不缓存 HTML,需 Cache Rule 显式开启「Eligible for cache」
- 自查:`curl -I` 看响应头;第二次请求 `cf-cache-status: HIT`(或对应 CDN 的命中标)
