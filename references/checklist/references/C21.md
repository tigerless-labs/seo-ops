# C21 · YMYL trust block (P0)

## Introduction

Medical/insurance/finance content (YMYL) is a priority target of Google's quality systems: mass-produced pages with no byline and no review attribution can drag down the **whole site**. The trust block = page-visible evidence of E-E-A-T.
Depends on the ymyl verdict (T4) and on review actually happening (R2), hence assigned to human review.

## Implementation guidance

- Template the trust block; machine anchors follow the DOM anchor contract (`data-seo-*`; UI styling is free, anchors stay stable):

```html
<!-- Example (for reference only; anchors are this system's DOM anchor contract, E-E-A-T elements per Google's quality guidelines) -->
<div data-seo="byline">
  Author: <a href="/authors/dr-wang">Dr. Wang</a>, licensed insurance broker (CA #0X12345)
</div>
<div data-seo="reviewed-by">
  Reviewed by <a href="/authors/dr-li">Dr. Li</a> · 2026-08-01
</div>
<time data-seo="last-updated" datetime="2026-08-20">Last updated: 2026-08-20</time>
```

- Citation lists use authoritative sources only (domain in `authority-sources.yaml`: official/government/academic/industry authorities)
- Person JSON-LD and the DOM render **from the same source** (the same data row; see [C12.md](C12.md) section 3)
- Author pages (/authors/x) establish an entity for each author: bio + credentials + sameAs (professional registration page, etc.)
- Human review: before launch, walk C21's YMYL trust block checklist item by item; **review must actually happen, no name-lending** (R2 red line)
